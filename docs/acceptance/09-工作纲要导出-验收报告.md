## 二、实现说明

### 数据层

- 迁移 v6 新增 `summary_drafts`:`period_type('month'|'week'|'custom') + period_key` 唯一,`content` 保存纲要 JSON,含 `created_at/updated_at` 与更新时间索引
- `src/main/db/repositories/summaries.ts`:`get / save(ON CONFLICT 更新) / remove / latest`,读取时对损坏内容容错回退为空纲要
- 模板保存在 settings `summary_template`;月末提醒标记保存在 settings `summary_month_reminded`(存月份,如 `2026-10`)

### 归集口径

- 任务:需 `status='done'`,按 `completed_at` 的日期落入统计周期
- 会议:需已召开(`status='done'` 或开始时间 ≤ 当前时间),按 `start_time` 日期落入周期
- 排除 `cancelled`;「完成工作项」统计不含会议;对接/报告统计按章节归类后计数
- 章节归类优先级:会议 > 报告材料(标题/描述含 报告|材料|总结|汇报)> 对接协调(有对接人 或 含 对接|协调|沟通)> 例行工作

### 周期与文案

- 月:`YYYY-MM` → 当月 1 日至月末;周:周一起算,`YYYY-MM-DD ~ YYYY-MM-DD`;自定义:任意起止日期
- 标题:月为「2026年10月工作内容纲要」,周/自定义为「起止日期工作内容纲要」
- 文件名经过 Windows 非法字符替换,导出时重名自动追加 `(2)`、`(3)`

### 导出实现

- Word:adm-zip 生成最小 OOXML(`[Content_Types].xml`、`_rels/.rels`、`word/document.xml`、`word/styles.xml`、`word/_rels/document.xml.rels`),含标题/章节/统计/条目/备注样式
- Excel:SheetJS 生成「工作纲要」与「导出说明」两个工作表;统计行、章节明细(章节/序号/日期/事项/工作内容)
- PDF:隐藏 BrowserWindow 渲染 A4 打印版 HTML 后 `printToPDF`;中文使用系统微软雅黑/宋体,单页版式
- 纯文本:带 BOM 输出,便于 Windows 记事本正确识别
- 渲染层调用 IPC 前用 `JSON.parse(JSON.stringify(...))` 转为纯对象,规避 Vue 响应式 Proxy 无法结构化克隆的问题

### 月末提醒

- 启动 3 秒后首次检查(等渲染层挂载应用内通知监听器),之后每小时检查
- 判断当天是否为当月最后一个工作日(周一至周五);是则检查当月草稿,无草稿自动按已归集数据生成
- 系统 Notification + `app:in-app-notify` 应用内通知(8 秒,点击跳转 `#/summary`);同月已提醒则不再触发
- 截图验收支持 `SUMMARY_MONTH_END_FORCE=YYYY-MM-DD` 模拟日期

### 5. 导出文件校验

- `file` 识别:docx = Microsoft Word 2007+;xlsx = Microsoft Excel 2007+;pdf = PDF 1.4,1 页;txt = UTF-8 (with BOM)
- TXT:标题、统计行、四章节 12 条事项、备注、生成时间完整,含手动补充事项
- XLSX:工作表 `[工作纲要, 导出说明]`;统计行与 12 条明细正确,含「换季保障材料归档」
- DOCX:包内 5 个 OOXML 部件齐全;`document.xml` 含标题、手动事项与备注
- PDF:渲染预览确认中文与版式(见 board09-pdf.png)
- 导出样例已归档至 `docs/acceptance/samples/board09/`,可直接用 Office/WPS/记事本打开复核

### 6. 验收中发现并修复的问题

1. **通知点击不跳转(影响全部提醒)**:主进程发送路由 `#/summary`、`#/meetings` 等,hash 模式下 `router.push('#/summary')` 会被拼成 `#/dashboard#/summary`。已在 `App.vue` 统一去除前导 `#` 后再跳转,系统通知与应用内通知共用该逻辑;月末通知点击已实测跳转成功。
2. **PDF 出现仅含生成时间的第二页**:压缩行距与章节/备注/页脚间距后,当前样例为单页 A4。
3. **月末提醒首次检查时序**:启动即检查可能在渲染层监听器挂载前发出应用内通知而丢失;改为启动 3 秒后首次检查,之后每小时检查。

## 四、用户复核步骤

1. 双击仓库根目录的 `启动应用.bat`,点击左侧「工作纲要」。
2. 默认展示当月纲要:核对四项统计与四个章节;切换「按周汇总」「自定义区间」查看归集结果。
3. 点击右上「⚙️ 模板设置」,尝试关闭统计卡片/备注/某个章节并保存,页面预览随之变化。
4. 点击「✏️ 编辑」:修改某条事项、在章节内「+ 添加事项」、编辑备注,点「💾 保存」;关闭应用再启动,确认草稿仍在。
5. 在右侧「导出选项」依次点击 Word/Excel/PDF/纯文本:文件保存到 `文档\工作台助手\工作纲要`;用 Office/WPS/记事本打开核对内容。
6. 点击「↻ 重新生成」或「恢复自动生成」,确认可覆盖/清除草稿。
7. (可选)若需验证月末提醒:以环境变量 `SUMMARY_MONTH_END_FORCE=2026-10-30` 启动开发版,可在非月末日期模拟最后一个工作日;正式使用中会在当月最后一个工作日自动提醒一次。

## 六、遗留事项与说明

- 统计卡片按日程/会议自动归集口径计算,手动补充的事项只进入章节内容,不改变四项统计数字(避免与源数据重复计数)。

- PDF 中文可正常显示与打印;文本层未嵌入 ToUnicode 映射,复制 PDF 文本可能只能得到部分字符,不影响查看与打印,板块 10 可评估完善。
