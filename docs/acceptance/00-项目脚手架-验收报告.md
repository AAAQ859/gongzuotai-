## 三、开发过程中发现并解决的问题

1. **TypeScript 7 与 vue-tsc 不兼容**:TS 7 移除了 `./lib/tsc` 导出,vue-tsc 无法运行。解决:固定 `typescript@~5.9.0`。
2. **本机系统环境变量 `ELECTRON_RUN_AS_NODE=1`**:会导致 Electron 以纯 Node 模式启动(窗口无法创建、`require('electron')` 返回路径字符串)。该变量按"存在即生效"判断,置空无效。解决:新增 [scripts/run.mjs](../../work-assistant/scripts/run.mjs) 启动包装,在启动前整体删除该变量,`npm run dev` / `npm start` 已接入。
3. **git-bash 启动 GUI 程序立即分离**:控制台不等待 GUI 进程,截图验收无法执行。解决:改用 PowerShell `Start-Process -Wait` 方式启动验收(已写入 README 验收方法)。
