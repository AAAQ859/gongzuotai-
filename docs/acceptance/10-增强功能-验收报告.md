## 二、实现说明

### 系统托盘与开机自启

- 主进程 `src/main/tray.ts` 用 `Tray` + `Menu.buildFromTemplate` 创建托盘;图标运行时用 32×32 BGRA 位图绘制(青绿 `#12B886` 圆角底 + 白色 W),不依赖外部资源文件
- 托盘菜单路由复用现有 `app:navigate` 通道(`#/summary`、`#/reminders`),与提醒通知点击同一套导航逻辑
- `win.on('close')` 按设置 `preventDefault() + hide()`;`before-quit` 标记 `quitting` 后放行,保证托盘「退出」/系统关机可正常结束进程
- 关闭到托盘默认开启;设置键 `tray_close_to_tray`(`1`/`0`),开机自启设置键 `auto_launch`
- 开发模式注册 `process.execPath + app.getAppPath()`;读取系统状态时使用同一组 `path/args`,避免 `getLoginItemSettings()` 误报未开启;打包后自动使用安装版路径(板块 11 验证)

### 工作统计图表

- 纯逻辑 `src/renderer/src/utils/work-stats.ts`:
  - `monthSlots`:最近 N 个月槽位(含当前月,跨年正确)
  - `monthlyTrend`:任务按 `completed_at` 归月;会议按 `start_time` 归月且已召开(`status='done'` 或开始时间 ≤ 当前);排除取消
  - `categoryBreakdown`:已完成任务按分类聚合,空白归「未分类」,超过 limit 合并「其他」,百分比一位小数
  - `contactActivity`:已完成任务按关联对接人聚合 Top N,联系人缺失/空名回退「未知联系人」
  - `niceMax`:1/2/5×10ⁿ 整齐刻度(最小 1);`barHeight`:数值→柱高映射
- 组件 `WorkStats.vue`:纯 SVG 柱状图 + 横向占比条,无第三方图表依赖;1200px 两列、760px 单列,趋势图最大宽度 620px 居中,避免窄窗口把 SVG 连文字一起放大
- 仪表盘在此前汇总卡、今日日程、迷你月历、待对接之后追加统计区块;空数据时显示空态文案

### 数据备份与恢复

- 备份:`VACUUM INTO` 生成包含 WAL 的一致性数据库副本 → 生成 `manifest.json`(应用/类型/版本/结构版本/创建时间/各表数量/`includesFiles:false`)→ `adm-zip` 打包 `manifest.json + work-assistant.db`
- 文件名 `工作台助手备份-YYYYMMDD-HHmm.zip`;同分钟重名自动加 ` (2)`
- 备份内容:日历、事项/会议、联系人、文件板块索引、纲要草稿、提醒、设置;**不含文件板块中的实际文件**
- 恢复校验顺序:
  1. ZIP 可读且含 `work-assistant.db`、`manifest.json`
  2. 清单 `app/kind/version/appVersion/schemaVersion/createdAt/includesFiles/counts` 严格校验
  3. 清单结构版本不得高于当前应用
  4. 数据库 `PRAGMA integrity_check = ok`、必需表存在、库内结构版本不高于当前
  5. `VACUUM INTO` 保存恢复前安全副本到 `userData\db\backups\恢复前自动备份-<时间戳>.db`
  6. 关闭数据库 → 删除 db/-wal/-shm → 复制备份库 → 重新打开并执行迁移(旧备份自动升级);失败时回滚安全副本
- 恢复成功后写入 `last_backup_at / last_backup_path`,界面提示安全副本路径;点「重新载入」刷新渲染层数据
- 截图验收支持 `SCREENSHOT_BACKUP_DIR`(跳过保存对话框)、`SCREENSHOT_BACKUP_RESTORE`(跳过选择对话框),正式使用均弹出系统原生对话框

### 设置页

- 新增「系统托盘与启动」:关闭到托盘开关、开机自启开关、托盘状态、托盘菜单预览
- 新增「数据备份与恢复」:默认备份位置、上次备份时间/文件、立即备份、从备份恢复、打开备份文件夹、说明文案
- 恢复确认弹窗明确说明会覆盖哪些数据、文件板块实际文件不受影响、会自动保存安全副本

## 四、验收中发现并修复的问题

1. **开发模式开机自启状态误报**:`setLoginItemSettings({path, args})` 后直接 `getLoginItemSettings().openAtLogin` 返回 `false`,导致开关点了又弹回。已改为设置与读取共用同一组 `path/args`(`loginItemOptions`),实测开启后 `true`、关闭后 `false`;测试结束已清理注册表项。
2. **恢复后「上次备份」记录丢失**:备份包生成时尚未写入 `last_backup_at/path`,恢复旧设置后记录消失。已在恢复成功后按清单时间与实际备份文件路径重新写入。
3. **恢复成功提示换行被吞**:`ElMessageBox` 默认不保留 `\n`,数据摘要与安全副本路径连成一段。已加 `customClass` + `white-space: pre-line`,分行显示。
4. **窄窗口趋势图整体放大**:趋势面板横跨整行时 SVG 连文字一起放大。已限制图表最大宽度 620px 并居中,1024×700 下文字与柱宽正常。
5. **`zip.readFile` 可能为 null**:TypeScript 类型检查报错。已增加空值校验并给出「备份包中的数据库文件为空」提示。
6. **演示数据缺少历史月份**:统计图表此前只有近两个月的点。已在 `seed-demo` 增加 8 条历史完成事项/会议(不影响当月纲要统计),用于趋势/分类/对接人演示与验收。

## 五、用户复核步骤

1. 双击仓库根目录的 `启动应用.bat`,进入「仪表盘」,向下滚动查看「完成趋势 / 事项分类 / 对接人活跃度」;缩放窗口到较窄尺寸确认自动重排。
2. 进入「设置」:
   - 「系统托盘与启动」:关闭再打开「关闭窗口时隐藏到托盘」,点窗口右上角 ×,确认窗口隐藏但应用仍在托盘运行;单击托盘图标恢复窗口;右键托盘图标查看菜单。
   - 打开「开机自动启动」,在 Windows「设置 → 应用 → 启动」或任务管理器启动项中确认;复核完成后请关闭开关。
3. 「数据备份与恢复」点「立即备份」:在系统「另存为」对话框中选择位置(默认 `文档\工作台助手\备份`),确认生成 ZIP 与页面上的备份时间/路径。
4. 修改一条数据(如新增联系人/事项),再点「从备份恢复」选择刚生成的 ZIP;确认提示后等待恢复成功,点「重新载入」,确认数据回到备份时状态。
5. 可尝试选择一个普通 ZIP:应提示「不是工作台助手的备份包」,现有数据不受影响。
6. 注意:备份只含数据库内容,不含文件板块中的实际文件;恢复后这些文件需仍在原路径。
