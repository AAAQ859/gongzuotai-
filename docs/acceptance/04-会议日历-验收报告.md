## 二、统计口径(设计决策,供后续板块沿用)

- **会议数据与日程日历互通**:同一 events 表,kind='meeting' 且日历 kind='meeting' 的才在会议页展示;任务事项一律不出现
- **时间轴收敛规则**:早于 08:00 的开始收敛到轴顶;开始时间 ≥ 18:00 的会议不参与时间轴布局;无开始时间不参与;无结束时间按开始 +30 分钟计(最少 15 分钟高)
- **重叠分列**:贪心分列保证同列不重叠;列宽按「与该块实际重叠的块数」均分,尾接/错峰的会议不被压窄
- **下一场会议** = 当日未结束且未取消中开始时间最近的一场(已开始未结束的计「即将开始」);无则显示「今日会议已全部结束」
- **会议清单汇总**:共 N 场(排除已取消) · 已结束 M 场(有结束时间且已过);右栏跟随时间轴当前日(今天则文案用「今日」)
- **头像**:参会人缩写取名字首字符,颜色取联络接口头像色(无 contact_id 用灰);最多展示 3 个 + "+N"
- **地点图标**:含 线上/视频/腾讯/Zoom/Teams/Webex 关键词显示 💻,否则 📍
- **会前提醒(会议级)**:会议编辑器按 PRD 不提供逐场设置,统一由「提醒设置」弹窗的 settings 值驱动;会议事件本身沿用事件级 reminder_enabled/reminder_minutes(编辑器默认开启 30 分钟,与事项一致)
- **编辑器共享**:新建会议复用板块 03 编辑器,`default-kind="meeting"` 隐藏对接人/状态/结束前提醒(事项专属字段),只显示会议日历/地点/参会人

### 3.5 验收中发现并修复的缺陷

| 缺陷 | 现象 | 修复 |
|------|------|------|
| label 转发点击 | 侧栏行用 `<label>` 包裹 checkbox,点击行体时浏览器默认行为向 checkbox 转发点击,导致「只看该日历」连带翻转可见性,列表被清空(真实鼠标用户必现;板块 03 的注入脚本用 dispatchEvent 未触发默认行为才未暴露) | 行体点击处理器 preventDefault 取消转发;CalendarView 与 MeetingsView 同步修复,复验 DB is_visible 不再被翻转 |
| Vue Proxy 无法过 IPC | 会议编辑器提交 reactive Proxy 数组,Electron 结构化克隆报「An object could not be cloned」保存失败(事项路径发字面量 [] 未触发) | 提交前 map 为普通对象拷贝 |

## 四、用户复核要点

1. 双击 启动应用.bat → 左侧导航「会议日历」:日视图时间轴应显示今日会议,重叠会议并排;右侧显示「今日共 N 场 · 已结束 M 场」、下一场会议倒计时、今日/次日清单
2. 点击侧栏「客运部会议日程」行 → 只看该类会议;再点一次取消;勾选框单独控制显隐(两者互不影响)
3. 周/月视图只出现会议,不出现待办事项
4. 「新建会议」→ 类型固定会议,默认今天 09:00-10:00,保存后时间轴/右栏立即出现
5. 「🔔 提醒设置」→ 保存后可到「设置」页或 DB 中确认;通知弹出由板块 06 实现
6. 「⚙ 管理日历」→ 只管理部门日历
