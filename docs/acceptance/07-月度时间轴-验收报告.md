## 二、统计口径(设计决策,供后续板块沿用)

- **数据同源**:时间轴与日历共用 events 表,不新建表;节点「主日期」= start_time 的日期,无 start 则取 end_time(均无不出现在时间轴)
- **状态判定顺序**:done/cancelled 优先 → in_progress → 有截止且 end < 今天=已逾期 → end 为今天=今日截止 → 主日期为今天=今日 → 其余待开始
- **排序**:日期升序 → 同日按开始时间升序(无时间排后)→ 同时间戳按 sort_order → id,稳定排序
- **汇总口径**:已完成=done;进行中=in_progress+今日+已逾期+今日截止;待开始=pending;已取消不计入总数
- **月份归属**:主日期落在所看月份内才显示(如「国际航班换季计划确认」主日期 10-21、截止 10-23,只出现在 10 月)
- **导入列**:日期(必填)/标题(必填)/描述/日历/分类/开始时间/结束时间/对接人;表头判定「首格是列名,或(首格不是有效日期且行内有列名)」——数据行首格必为日期,标题恰好叫「事项」等列名时不会误判为表头
- **催办中标签**:category=对接 且(已逾期 或 今日截止)
- **本月进度**:round(今天 / 本月天数 × 100),今天占一天,月末为 100

### 3.5 验收中发现并修复的缺陷

| 缺陷 | 现象 | 修复 |
|------|------|------|
| 导入表头误判 | 数据行 `['10-05','事项',…]` 因标题恰好是列名「事项」被当成表头,该行被跳过 | detectHeader 先判首格:首格是有效日期 → 必为数据行;仅当首格不是日期且行内含列名时才视为表头 |

## 四、用户复核要点

1. 双击 启动应用.bat → 左侧导航「时间轴」:10 月纵向时间轴,今天组标【今天】;绿点已完成、红点已逾期/今日截止、青点进行中/今日、灰点待开始;「航线资料催收」「向质安部索要Q3质量数据」等带琥珀「催办中」标签;左侧主线绿色渐变高度约为本月已过 68%
2. 顶部「‹ 今天 ›」切月(如切到 9 月应看到空态提示);点日历 chips(如「对接事项」)只显示该日历节点,汇总数随之变化
3. 点击「向质安部索要Q3质量数据」→ 右侧详情含 📱 电话:138-0000-1234;点「✓ 标记完成」→ 节点变绿点、汇总「已完成」+1;再点「↺ 恢复待办」还原;「✏️ 编辑」打开编辑器改标题保存后列表即时刷新
4. 点「+ 添加节点」→ 默认类型待办、日期今天,保存后出现在今天组
5. 点「📥 导入文件」→「选择 Excel/CSV 文件」选一个含 日期/标题 列的 Excel → 出现预览表与提示行(缺日期/标题的行),点「导入」→ 提示成功,时间轴出现新节点;日历列填新名字会自动创建新日历 chip
