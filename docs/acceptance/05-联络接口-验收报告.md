## 二、统计口径(设计决策,供后续板块沿用)

- **拨号/微信(与用户确认)**:离线桌面无法直接拉起微信,拨号采用系统 `tel:` 协议唤起默认电话软件,无电话软件时 toast「无法唤起电话拨号」;微信按钮复制微信号到剪贴板,toast「微信号「X」已复制,请在微信中搜索」。`shell:openExternal` IPC 仅放行 tel: 协议,其余一律拒绝(安全白名单)
- **待跟进判定**:events 中 kind=task、category=对接、contact_id 非空、未完成未取消,且 end_time 已过(已逾期)或 ≤ 本周六 23:59;横幅按截止时间最早的展示,并显示「另有 N 位联系人待跟进」
- **截止文案**:已逾期 / 今日 / 明日 / N天后(按自然日差)
- **导入解析(Excel 与 CSV 共用语义层)**:主进程 SheetJS 将 xlsx 首个工作表解析为字符串网格(xls 兼容读取),CSV 走既有行解析;渲染层 `parseContactsRows` 统一做表头识别(姓名|名称|name、部门、职位、电话、微信、邮箱、备注,中英文均可,无表头按固定列序 姓名,部门,职位,电话,微信,邮箱,备注);CSV 额外支持双引号包裹与 `""` 转义;缺姓名行跳过并提示「第 N 行缺少姓名,已跳过」
- **头像色**:8 色循环 #339AF0/#12B886/#9775FA/#FF922B/#F06595/#51CF66/#22B8CF/#F59F00,新建按当前联系人总数取模;群组头像显示 💬
- **排序**:按姓名(中文拼音 localeCompare)、常用优先(⭐ 在前)、待跟进优先(截止最近在前)

### 3.5 验收中发现并修复的缺陷

| 缺陷 | 现象 | 修复 |
|------|------|------|
| Vue Proxy 无法过 IPC(联络保存链路) | 编辑器提交 `form.group_ids`(reactive Proxy 数组)给 setGroups,Electron 结构化克隆报「An object could not be cloned」:联系人已写入数据库但弹窗不关闭、列表不刷新,再次点击保存会产生重复记录(e2e 注入脚本实测复现) | 提交前展开为普通数组 `[...form.group_ids]`,复验:保存后列表立即刷新、无重复落库 |
| 截图脚本含 TS 语法 | 导入弹窗脚本用 `as HTMLButtonElement` 断言,executeJavaScript 仅支持纯 JS | 改为纯 JS 写法 |
| 截图模式 userData 相对路径 | `app.setPath('userData', 相对路径)` 抛「Path must be absolute」,应用挂错误框 | 改为绝对路径 |
