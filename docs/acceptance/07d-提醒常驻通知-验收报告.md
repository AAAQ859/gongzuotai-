# 板块 07d 验收报告:到点提醒应用内常驻通知

- 验收日期:2026-10-21
- 验收人:Claude(自动化验收)+ 用户(双击 启动应用.bat 复核)
- 触发:用户确认「到点提醒应用内通知常驻不自动消失」的需求

## 一、验收范围

| 编号 | 项目 | 说明 |
|------|------|------|
| F1 | 到点提醒常驻 | 提醒引擎触发的应用内通知 duration=0:不自动消失,直到用户点击(跳转对应页面并关闭)或点 × 手动关闭;应用最小化/离开后回到窗口仍能看到 |
| F2 | 测试通知保持即时 | 「发送测试通知」的应用内卡片仍为 8 秒自动消失(一次性反馈,不堆积) |
| F3 | 通道标记 | 主进程 payload 增加 persistent 标记:引擎发 persistent=true,测试通知 persistent=false;preload 类型同步 |
| F4 | 回归 | typecheck、build、全部测试通过 |

## 二、实现说明

- `app:in-app-notify` payload 增加 `persistent?: boolean`;App.vue 按标记设置 `duration: persistent ? 0 : 8000`
- 点击通知:有路由则跳转对应页面(截止→日程日历、会前→会议日历、催办→联络接口、晨间→仪表盘),并关闭该通知
- 常驻通知不影响提醒中心数据(仍由引擎写入 fired 行,提醒中心可随时回看)

## 四、用户复核要点

1. 「设置」→「发送测试通知」:应用窗口右下角弹「🔔 测试通知」,约 8 秒自动消失
2. 到点提醒触发(或把系统时间调到提醒时刻附近验证):应用内「截止提醒/会前提醒」卡片**不会自动消失**,点卡片跳到对应页面(并关闭),或点 × 关闭
3. 最小化应用再回来:常驻提醒仍在窗口右下角
