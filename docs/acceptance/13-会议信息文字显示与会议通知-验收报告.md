## 五、补充修正(2026-10-25 用户二次复核)

用户复核提出两点:会议信息标签与填写内容之间应有全角冒号「：」;日程日历月视图下方周四周五没有分隔线、混为一体。

### 1. 全角冒号补齐

- `TodoDialog.vue`:文字模式标签统一为「时间：」「地点：」「参会人：」「备注：」;标签与值紧邻,图标模式仍保留 4px 间距。
- `MeetingsView.vue`:日视图时间轴、周视图地点、右侧今日/次日会议均使用全角冒号;次日会议备注改为「地点：… · 备注：…」,不再与地点粘连。
- `CalendarView.vue`:日视图清单使用「地点：」「参会人：」「对接人：」。
- `DashboardView.vue`:今日日程使用「地点：」「参会人：」「对接人：」。
- 详情弹窗 `EventDetailDialog.vue` 为左右两列表格布局,标签与值分列显示,不加内联冒号。

### 2. 月视图列宽修复

- 根因:`.cal-month__grid` / `.cal-month__head` 使用 `repeat(7, 1fr)`,周五一个长标题把该列自动最小宽度撑大,导致周五列变宽、周四周五边界错位。
- 修复:表头与网格统一改为 `repeat(7, minmax(0, 1fr))`,单元格、事件容器增加 `min-width: 0` 与 `overflow: hidden`;周视图同步加固。
- 实测(1280×800 默认窗口):7 列宽度均为 109px,列右边界 570/680/789/899/1008/1118/1227,表头中心与列中心最大偏差 1px;截图与 DOM 证据见 [board13-calendar-month.png](screenshots/board13-calendar-month.png) 及同名 `.dom.json`。
